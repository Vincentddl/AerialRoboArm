# 正式AUTO：持续视觉跟随与人工夹爪

适用：默认FreeRTOS正式控制构建。不是`HC13_HOST_LINK`实验固件。更新：2026-11-06。

## 当前默认行为

1. ELRS有效且安全准入满足，SA请求AUTO。
2. 进入AUTO时先向夹爪发送130°张开预设。
3. 电脑发送有效视觉角度，主臂持续更新目标，不等待三帧确认再移动。
4. 无有效目标、低置信度或数据过期时进入保持逻辑，不采用无效新目标。
5. CH4正向>55%输出135°，回落<25%输出90°；进入AUTO后的首次CH4有效操作接管夹爪。
6. 急停、遥控失联、执行器故障等保护优先。AUTO切回MANUAL按反馈位置重置遥控增量目标，以减小目标跳变。

夹爪预设不是物理反馈，不自动判断抓取成功；抓取后的视觉确认/重试并非默认已实现功能。

## 正式视觉消息

```text
V,-30,100,90
V,-30,100,90,3
```

字段为`V,目标角度deg,速度deg/s,置信度[,稳定帧数]`；LF结束。目标采用HX8角度定义，负向前伸，限位−90°～+85°。目标需要存在、置信度≥60%、年龄<200ms。速度0选择AUTO默认上限500°/s，非零速度由执行层约束在20～500°/s；加减速各100ms，不代表机构实测速度或安全保证。

MCU可低频回复`ACK,累计视觉帧数,角度deg,置信度`，仅表明解析了消息，不表示到位。此ACK与V2事务ACK不同，不能混用解析器。实际字段容错以`drv_hc13.c`为准；对接应发送完整字段。

## 可选三帧方案

`AUTO_GRIP_THREE_FRAME=ON`才启用自动闭爪；默认OFF。启用后，仅新收到的稳定帧参与闭合计数，缓存重复读取不算新观察；硬件反馈健康和其他准入条件仍适用。该开关不把主臂跟随改成三帧延迟。

两种夹爪方案由`tools/test_auto_pick.ps1`验证软件逻辑。不要把启用开关或测试通过描述为已验证抓取成功。

源码：`task_vision.c`、`task_arbiter.c`、`task_manipulator.c`、`task_motion.c`。V2上位机的毫度候选V、PREP/PICK/TRIGGER另见[协议V2](HC13_HOST_PROTOCOL_V2.md)。
