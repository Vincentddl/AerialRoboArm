# 2026-11-01 最小更新

本次只在手动页增加 HX8 电压、具体故障说明、故障恢复按钮。保留手动 MOVE/GRIP 和已有视觉功能，不增加角度误差等可选功能。

- 电压来自 STATE.voltage_mv，单位 V；并非夹爪或 MCU 电源电压。离线或没有有效数据时显示未知，不猜测健康阈值。
- 故障显示设备实际 fault_code 及中文说明。
- 故障恢复复用当前 MCU 的 STOP：停止并保持，设备检查反馈后决定是否清除软件故障。收到 ACK 后立即查询 STATE；不会在本地直接清除故障。失败原因可在最近操作和日志中看到。
- 恢复不自动归零、不重发运动、不操作夹爪；离线时不能恢复。
- 未改 MCU 固件，无需因本次界面更新重新烧录。运动超时条件未修改，仍可能再次超时，需要检查位置误差或机构。

软件测试：全套39项通过；最新补测3项通过，包括实际上位机与MCU C模块模拟端的超时恢复往返。没有进行真实无线或舵机动作测试。

修改版压缩包带 Python 3.11 和依赖，适用于 Windows x64。完整解压后双击 start_windows.bat，不要在压缩包内运行。连接实际 HC13 端口、230400，关闭模拟。串口编号随电脑变化，按设备身份选择。
