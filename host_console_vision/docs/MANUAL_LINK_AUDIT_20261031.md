## 结论

当前上位机手动按钮与 MCU 实际 C 协议代码的软件互通通过；历史原始记录证明只读双向通信曾成功。当前没有枚举到 COM 口，未进行本次无线实机控制、烧录或舵机动作，不能宣称电机无线控制已实测打通。

## 关键区别

旧上位机手动出臂调用PICK，需要准备及开闭爪等待时间，当前未标定会被拦截。这个目录已经改为独立MOVE，并新增GRIP按钮。同伴旧压缩包不一定含有这些修改。

MOVE仍受MANUAL、HX8反馈健康、启动就绪和软件限位约束；开启记录时还要求IMU有效采样率满足条件。存在限制不等于协议格式错误。手动归零按钮发送普通MOVE，当前实际角度越界时不应期待它绕过恢复保护。
