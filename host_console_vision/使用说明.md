# 2026-11-01 最小更新

2026-11-22 补充：手动“按当前参数抓取”从正常位或折叠位起步，抓取后均以 INFO 上限的 10% 返回当前校准的折叠位；视觉抓取仍以 60% 返回本次起点。正常位、折叠位以校准模式当前保存值为准。以下 2026-11-06 的固定角度描述为历史记录，以运行时校准和 README 为准。夹爪无实际位置反馈。

当前设置：上位机夹爪闭合 PWM 90°、张开 PWM 125°，相差35°；正常模式和手动归零到 +50°后张开。视觉抓取闭爪后，HX8 直接返回 +50°并保持闭爪，不再自动张开。下方旧的105°／15°和“归零后闭合”描述已被本段取代；MCU固件内部预设未改。

原打包版本在手动页增加 HX8 电压、具体故障说明、故障恢复按钮，以及设备反馈的目标角度、实际角度和误差。夹爪安装时先卸下连杆，按“安装基准 90°”；待舵机停稳并保持通电，再将夹爪安装成闭合位。之后两个按钮分别发送张开 105°、闭合 90°，相差 15°。折叠模式先闭爪，收到 ACK 后将 HX8 以 40% 速度移至 +75°，相对固件+85°上限保留10°余量；正常模式和手动“归零”都使用绝对 +50°视觉工作位，以 60% 速度到位，收到 DONE 后闭合夹爪 PWM 90°。手动出臂角度从 +50°工作位计算，范围0～130°；例如出臂30°发送绝对+20°，出臂130°发送绝对−80°。控制层仍检查 CAL 标定端点−90°，不会越界；启动前要求实际位置位于 +50°±3°，否则先正常／归零。物理标定零点仍为 0°。夹爪无实际位置反馈。未改 MCU 自动动作的夹爪角度。

- 电压来自 STATE.voltage_mv，单位 V；并非夹爪或 MCU 电源电压。离线或没有有效数据时显示未知，不猜测健康阈值。
- 故障显示设备实际 fault_code 及中文说明。
- 故障恢复复用当前 MCU 的 STOP：停止并保持，设备检查反馈后决定是否清除软件故障。收到 ACK 后立即查询 STATE；不会在本地直接清除故障。失败原因可在最近操作和日志中看到。
- 恢复不自动归零、不重发运动、不操作夹爪；离线时不能恢复。
- 未改 MCU 固件，无需因本次界面更新重新烧录。运动超时条件未修改，仍可能再次超时，需要检查位置误差或机构。

软件测试：全套39项通过；最新补测3项通过，包括实际上位机与MCU C模块模拟端的超时恢复往返。没有进行真实无线或舵机动作测试。
