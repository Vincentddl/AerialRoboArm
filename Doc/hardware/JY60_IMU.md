# JY60 六轴姿态模块：参数与接入参考

整理日期：2026-10-19。

**接入状态：已提供独立串口 demo，并在原 ELRS 接口 USART1/PB6、PB7 上收到有效数据。** 默认完整固件仍使用 ELRS 配置，JY60 尚未接入机械臂闭环。测试固件不启动舵机控制。操作入口见 [JY60_UART_DEMO.md](./JY60_UART_DEMO.md)。

说明书第 3 页写明内部传感器为 **ICM-42605**。JY60 是模块型号，ICM-42605 是其描述采用的 IMU 芯片，集成三轴加速度计、三轴陀螺仪和温度传感器。模块另有 MCU、稳压及滤波/姿态解算电路，MCU 的具体型号未在该说明书中明确。

供应商商品标题曾标注 MPU6500，且资料可能混有不同硬件修订。**实物芯片型号尚未确认**，应以商家对应批次资料或芯片丝印确认；不要仅凭本资料推断裸芯片寄存器或温度换算。芯片参考：[TDK ICM-42605](https://www.invensense.tdk.com/en-us/products/inertial-sensors/icm-42605)。

## 2. 关键参数

下表取自说明书第 3～5、9、12、15～19 页。

| 项目 | 资料规定 | 项目使用说明 |
| --- | --- | --- |
| 类型 | 六轴 IMU 姿态模块 | 六轴指三轴加速度 + 三轴角速度；姿态角由算法计算。 |
| 模块供电 | 3.3～5 V | 不接 PTK 的 7.4 V 或 HX8 的约 12 V 电源；裸 IMU 芯片额定电压不能直接套用于模块。 |
| 工作电流 | <10 mA | 厂家标称值，实际供电和纹波需测量。 |
| 休眠电流 | <10 μA | 厂家标称值。 |
| 对外接口 | TTL UART，9600 baud，8N1 | 固定波特率，不使用 RS232 电平。 |
| 输出速率 | 20 Hz | 每 50 ms 顺序输出三种数据包；不是 MCU 控制循环频率。 |
| 加速度范围 | ±16g，X/Y/Z 三轴 | 包含重力，静止水平时通常约为 (0, 0, 1)g。 |
| 角速度范围 | ±2000°/s，X/Y/Z 三轴 | 单位 °/s，表示转速而非角度。 |
| 姿态角范围 | X/Roll、Z/Yaw 为 ±180°；Y/Pitch 为 ±90° | 欧拉角接近 Pitch ±90°时存在耦合和奇异性，不能直接把该轴视为任意安装下的完整关节角。 |
| 角度标称精度 | 静态 0.05°、动态 0.1° | 是本版手册声明，不是项目实测精度；不同公开资料数值不一致，接入后需独立验证。 |
| 默认静止阈值 | 0.122°/s | 小于阈值的角速度可能输出为零；手册特别提示匀速转动测量可能有问题。 |
| 默认测量带宽 | 10 Hz | 滤波与 20 Hz 输出会影响动态响应。 |
| 磁力计 | 无 | 无磁北方向参考，Yaw 有积分漂移。 |
| I2C | 本型号不支持 | SCL/SDA 在引脚表中标为 NC 预留；不能连接现有测距 I2C 后直接读取。 |
| 记录存储 | 手册说明模块不带数据记录存储芯片 | 数据需由 MCU/电脑记录；手册另称模块配置可掉电保存，不等于可保存连续测量日志。 |

### 输出数据与能力边界

- **测量数据**：Ax/Ay/Az 加速度、Wx/Wy/Wz 角速度；协议还带芯片内部温度字段。
- **解算数据**：Roll/Pitch/Yaw 姿态角，通过加速度和角速度融合获得。
- **不直接测量**：舵机扭矩、电流、泡沫距离、三维位置或世界坐标。单靠加速度积分不能保证可靠位置测量。
- Roll/Pitch 可利用重力约束，但快速加减速、振动、安装偏差仍会引入误差。Yaw 主要依赖积分，归零只改变参考，不能消除后续漂移。

## 3. 接线

依据说明书第 5～7 页，以模块实物丝印为准，不仅凭焊盘外观辨认。

| JY60 引脚 | 功能 | MCU / USB-TTL 连接 |
| --- | --- | --- |
| VCC | 模块电源输入 | 经确认的 3.3 V 或 5 V |
| GND | 地 | 与接收端共地 |
| TX | 串口数据输出 | 接接收端 RX |
| RX | 串口指令输入 | 接发送端 TX；仅接收测量数据时可以不接 |
| SWIM | 调试/编程接口 | 常规姿态读取不用 |
| D0/D2/D3/SCL/SDA | NC 预留 | 不作为当前型号可用业务接口 |

可先用 VCC、GND、TX 三根线接 USB-TTL，在电脑端以 9600 baud 验证数据。USB-TTL 的供电与逻辑电平需分别确认，STM32 侧不能接 RS232 正负电平。DAPLink 的 COM4 不是已接好 JY60 的证明。

### 与当前 MCU 资源的关系

当前资源以 [pinmap.md](./pinmap.md) 为准：USART1/PB6、PB7 用于 ELRS（420000 baud），USART2/PA2、PA3 用于 HX8，USART3/PB10、PB11 用于 HC13。

独立 demo 已在 `JY60_UART_DEMO=ON` 时将 USART1 改为 9600 baud，并使用专用解析器。需物理断开接收机，不能把 JY60 与 ELRS 输出并接。默认完整固件仍是 420000 baud 的 ELRS 配置，不能仅因 VOFA 已绕开 ELRS 就认为 USART1 已自动变更。

## 4. 数据包格式

依据说明书第 16～19 页。输出为二进制字节，不是可直接显示的 ASCII 数字。每组由加速度、角速度和角度三个包构成，每包 11 字节，共 33 字节。

| 字节 | 内容 |
| --- | --- |
| 0 | 帧头 `0x55` |
| 1 | 类型：`0x51` 加速度、`0x52` 角速度、`0x53` 姿态角 |
| 2～3 | 第一轴数值，低字节在前 |
| 4～5 | 第二轴数值，低字节在前 |
| 6～7 | 第三轴数值，低字节在前 |
| 8～9 | 温度字段，低字节在前 |
| 10 | 前 10 个字节累加的低 8 位：`sum(bytes[0:10]) & 0xFF` |

三轴原始数据应按**有符号 16 位、小端**还原：

```c
int16_t raw = (int16_t)((uint16_t)lo | ((uint16_t)hi << 8));
```

| 数据 | 换算 |
| --- | --- |
| 加速度 | `raw / 32768.0 * 16.0`，单位 g |
| 角速度 | `raw / 32768.0 * 2000.0`，单位 °/s |
| 姿态角 | `raw / 32768.0 * 180.0`，单位 ° |

将来实现接收器时应支持串口分段、连续多包、校验失败后的重新同步和数据超时，不能假定每次串口读取恰好得到完整 11/33 字节。

## 5. 校准及配置命令

以下是说明书第 16 页列出的**三字节二进制命令**，仅作为协议参考，当前 MCU 控制台没有实现这些命令，不能在 VOFA 输入相同文本就当作已发给 JY60。

| 字节序列 | 含义 |
| --- | --- |
| `FF AA 52` | Z 轴角度归零 |
| `FF AA 67` | 加速度计校准 |
| `FF AA 60` | 休眠 / 解休眠切换 |
| `FF AA 65` | 水平安装配置 |
| `FF AA 66` | 垂直安装配置 |

上电后先静止，等待自动校准。手册的加速度计校准要求水平静止，约 1～2 秒后检查 (0,0,1)g；Z 轴归零不等于机械臂关节或 HX8 编码器归零。避免在运动中自动发送校准或休眠切换命令。

## 6. 资料差异与待核验项

| 项目 | 问题与处理 |
| --- | --- |
| 芯片型号 | 商品页 MPU6500 与手册 ICM-42605 不一致；实物待确认，不写死芯片身份。 |
| 温度换算 | 协议表给出 `raw/340 + 36.53`，示例却用 `raw/340 + 36.25`；不混用 IMU 裸芯片公式，先与实物/厂家核实，不能据此做温度保护。 |
| 角速度分辨率 | 参数表写 0.61°/s，但数据协议尺度计算为 `2000/32768 ≈ 0.0610°/s/LSB`；解析依据数据协议并实测，而非把 0.61 当作缩放系数。 |
| 波特率单位 | 参数表写有 `9600kps`，通信及上位机章节明确为 9600；按 9600 baud 使用。 |
| 外形与精度 | 手册高度同时出现 2 mm / 4 mm，不同资料精度也有差异；安装尺寸和性能以对应实物为准。 |

## 7. 本项目建议的初次验证

1. 先确认型号、供电和串口电平，用 USB-TTL 读取并校验三类包，记录真实输出周期。
2. 模块固定在实际连杆上，标定坐标轴、正方向和零位；优先选择重力可观测的倾角测量，避开 Pitch ±90°奇异位置。
3. 同时记录 HX8 编码器角度和 IMU 姿态，评估静态偏差、往返重复性、齿轮/舵盘打滑与动态延迟。
4. 第一期只作为独立测量参考。20 Hz 输出、10 Hz 默认带宽和静止阈值均可能影响速度，未实测前不替代 HX8 原有反馈、不直接增加主臂运动等待。
