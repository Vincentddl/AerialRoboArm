# HX8 静止位置误差修正

软件版本加入有上限的外部位置修正，作用于 RC、RTT 和 HC-13 的稳定目标。请求角度仍是原来的目标，发送给 HX8 的角度可能附带小幅补偿。速度、功率和硬限位 `-90°～+85°` 保持原设置。

## 条件与参数

- 新目标立即走原有运动路径，精度修正不会先等待再执行转动；主运动速度和 40 ms 最小变化目标发送间隔保持原值。
- 到位修正要求目标稳定至少 300 ms，并有连续两个稳定反馈间隔（初始位置变化不超过 0.15°）。补偿开始后允许本次补偿自身造成的不超过 0.25° 的小幅变化。
- 只计入新收到的反馈，缓存值不会重复积累修正。
- 反馈年龄小于 140 ms，电压 9.0～12.6 V，没有硬件故障位。
- 原目标到编码器的误差在 0.3～3.0° 时，每 100 ms 使用误差的 35% 作为修正步长，并限制在 0.1～0.2°；总补偿最多 ±1.5°。仍只在新有效反馈到达时更新。
- 达到 0.3° 死区后保留当前补偿；补偿也受全局软限位约束，不会在边界继续积分。
- 目标改变、失去反馈、故障或关闭力矩时清除补偿。误差在修正后增大超过 0.5° 时清除并锁住当前目标的修正，需新目标或力矩/链路切换才重启。
- 未变化的目标重发周期由 200 ms 改为 1000 ms；反馈仍约 10 Hz，变化目标仍遵循 40 ms 最小指令间隔。

RTT 发送 `z` 可切换修正开关，用于同一固件下的对照试验，重启后恢复默认开启。`TASK_MOTION_POSITION_TRIM_ENABLE=0` 可在编译时关闭修正。关闭修正时相同目标的重发周期仍为 1000 ms，若比较原固件，需同时恢复旧重发参数。

## 日志

原 `[DBG] tgt/pos` 仍分别表示用户请求角和编码器角；新增：

```text
[POS] sent_ddeg=-705 trim_ddeg=-5 valid=1 cap=0 block=0 enabled=1
```

`ddeg` 是 0.1° 单位，上例最近 UART 发送角度 -70.5°、控制器计算的补偿 -0.5°。发送失败或等待最小间隔时，计算补偿可能尚未发送；应结合 `sent_ddeg`、`wr` 和 `pos` 判断。`valid=0` 时没有有效的最近发送目标；`valid=1` 也不等于舵机已执行，实际位置仍以编码器回读为准。`cap=1` 表示补偿受限，`block=1` 表示误差增长后停止该目标的补偿。

## 验证与适用限制

`tools/test_position_trim.ps1` 编译并运行纯 C 控制器模拟测试，覆盖正负偏差收敛、重复缓存、断链/故障、移动目标、限幅、计时回绕和协议十分之一度的四舍五入。模拟不证明实机精度，真实机械负载、间隙和内环响应仍需测试。

`tools/test_position_trim.ps1 -CompareBaseline` 用相同 C 逻辑对比旧参数（600 ms 等待、200 ms 周期、0.1° 固定步长）和快参数。固定 ±1.2° 偏差模型中，进入 0.31° 误差带的时间从 2200 ms 降到 700 ms；延迟、噪声及十分之一度量化模型另行检查收敛和过冲。上述时间不包含真实大幅转动，不作为实机速度保证。

烧录前支撑机械臂。先在中间位置、小幅角度变化下测试 5～10 秒保持，再逐步检查往返方向。记录 `tgt`、`pos`、`sent_ddeg`、`trim_ddeg` 与电压、状态位，观察误差及是否抖动。达到补偿上限后仍有误差，不能直接扩大补偿，应排查负载和机构。

修正启用后，“名义 g 命令→视觉角”的关系会改变；原视觉命令表需要重新验证或标定。编码器与视觉角的几何关系也需核对安装未变化。新视觉自动标定不能沿用优化前的测试结果作为上线证明。
