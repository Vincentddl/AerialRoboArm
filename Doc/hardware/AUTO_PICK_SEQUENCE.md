# AUTO 连续跟随与三帧夹爪闭合

## 2026-10-23 AUTO 速度参数更新（源代码，尚未刷入采集固件）

PC消息的speed=0现在选择现有软件上限500°/s，非零速度继续限制在20～500°/s。加速、减速时间均为100ms；按线性加减速近似，名义加速度为5000°/s²。现有FSUS驱动允许最高750°/s，因此500°/s可被编码，但不代表实际舵机在当前负载下能够达到该速度或已证明安全；协议允许的最小20ms也不是机构已验证的最小安全时间。仍需检查机构、供电、跟踪误差与停止距离，短行程可能达不到最高速度。手动速度、角度限位、保护仲裁和夹爪方案开关未改变。本次只编译新参数，板上保留原HX8/JY61P采集程序。

## 2026-10-11 当前默认方案：视觉跟随 + CH4 手动夹爪

默认 `AUTO_GRIP_THREE_FRAME=OFF`：AUTO 只持续更新 HX8 视觉目标，夹爪直接采用遥控器 CH4 角度。进入 AUTO 先下发 130°张开并保持，直到操作 CH4 后接管；三帧识别不自动闭合；视觉丢失时主臂保持上一目标，CH4 仍可操作夹爪。CH4 向右超过 55% 下发 135°，低于 25%（含回中）恢复 90°。RTT `p 0 <角度>` 仍可覆盖，`p 0 -1` 释放。急停和故障保护仍生效。

原三帧方案源文件、已校验固件及视觉启动配置已保存至 `outputs/scheme_backups/auto_grip_three_frames_20261011.zip`。也可重新配置 `cmake -S . -B cmake-build-debug -DAUTO_GRIP_THREE_FRAME=ON`，编译并烧录恢复该方案。默认手动方案使用 `OFF`。`tools/test_auto_pick.ps1` 同时验证两种方案。

下文为保留的三帧方案说明，只有启用 `AUTO_GRIP_THREE_FRAME=ON` 时适用。

大舵机持续跟随有效视觉目标；夹爪每次进入 AUTO 先发送 130°张开指令，连续三帧稳定识别后发送 90°闭合指令。闭合不冻结主臂目标，后续视觉角度仍然更新。闭合后保持到退出 AUTO；再次进入重新张开。

遥控器从其他模式切入 AUTO 时，清除之前的 RTT `g` 主臂强制控制和 `p` 夹爪/姿态角度锁定。AUTO 入口的首个控制周期优先发出张开指令，并清零稳定帧计数；进入后新输入的 `p` 调试覆盖仍可单独控制夹爪。

## 两个独立条件

- 主臂：PC 保持单帧发送、GPU 推理。最新有效目标通过 HC13 后，在 20 ms 控制更新中采用；没有额外三帧运动延迟。
- 夹爪：同一 track，单帧置信度 ≥60%，标定范围与中轴条件有效，连续三帧推算角度最大差 ≤2°。PC 的独立稳定门输出 0..3；无目标、换目标或不稳定会重置。
- MCU 只按新 HC13 帧计数，不按控制循环计数；AUTO 进入时已有的缓存稳定消息不算新帧。至少收到三条新的有效观察，并且 PC 稳定值达到 3 后，才允许闭合。
- 闭合无需等待大舵机到位，完全依照本次三帧识别条件。PWM 舵机无位置反馈，张开/闭合仅能确认指令，不能确认物理端点或抓取成功。

## 协议

PC 使用 `V,<g>,<speed>,<confidence>,<stable_frames>`，例如 `V,-60,0,90,3`。MCU 继续兼容旧四字段 V 包，用于主臂跟随；旧包的稳定值为 0，不会触发自动闭合。ACK 仍是原来的四字段格式。

ELRS 在线、正常 AUTO、急停、视觉时效、主臂反馈及电压保护继续保留。反馈故障或视觉无效时，未闭合夹爪的三帧计数重置；已闭合则保持夹持，不自动反复开合。主臂不采用无效新目标。SERVO2/PA1 仍禁用。

`p 0 <角度>` 单独覆盖夹爪但不停止主臂跟随；覆盖期间不累计闭合条件。`p 0 -1` 解除覆盖。RTT g 强制控制取消正常 AUTO 周期。

## 观察与使用

`[PICK] stage=N grip=M stable=K`：2=张开并跟随，3=已闭合且继续跟随，4=张开保持；K 为 MCU 收到的新稳定帧计数，最多 3。stage=3 不再意味着主臂停止更新。

MCU 固件和 PC 程序都需要更新：重新烧录后重启 `start_fast_vision_control.bat`，使用 COM3 和模拟图传 source 1，按 A 开启发送。现有候选角度表继续使用，不恢复旧安装的 8 月表。

`tools/test_auto_pick.ps1` 测试真实状态机和 HC13 解析器；PC `tests/test_hc13_link.py` 验证独立门和四/五字段编码。测试覆盖缓存不计数、AUTO 重入张开、失稳/故障重置、旧包不触发闭合，以及闭合后连续更新主臂目标。
