# RTT 日志模式

默认每秒输出一行 `[DBG]` 简洁状态。`rc`/`vis` 为 ELRS/有效视觉在线状态；`pos`/`tgt` 为 HX8 实际/目标角度；`grip` 为夹爪指令角度，无实测反馈；`voltage` 为 HX8 毫伏，`status` 为状态位，`fb_age` 为反馈年龄（毫秒），`home` 为回零阶段，`health` 为 HX8 反馈健康判定。`health=OK` 不代表 ELRS 在线或回零完成，需同时查看 `rc`、`home`、模式。

输入 `d` 并发送换行，在详细和简洁日志之间切换。详细模式恢复 DBG/SAFE/BUS/PWR/POS/PICK/HOME 字段。输入 `r` 单独切换遥控器原始通道输出。`?` 查看帮助。重启默认恢复简洁模式。

ELRS 连接、HX8 异常及回零阶段的变化在 100 ms 调试周期检查，不重复刷屏。回包已恢复但电压或状态保护未通过时，输出相应保护原因，不将其误标为无回包。回零等待的多个条件仍可在简洁行中查看。

视觉工具兼容原详细日志及新简洁日志：启动检查从 `home=N` 读取回零状态；日志记录正确解析十六进制状态位。部署新固件后应重启正在运行的视觉记录程序，以加载更新的解析逻辑。
