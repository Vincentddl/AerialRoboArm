# VOFA 手动控制，不依赖 ELRS（2026-10-17）

正常启动仍保留遥控器控制。操作者通过 RTT/VOFA 明确发送 `h` 后，才选择 VOFA 手动控制权。这个入口使用原 HX8 调试对象（`debug=HX8`），但现在不再要求 ELRS 在线。`rc` 始终显示真实接收机状态，不会伪报在线。进入后先完成原有 0°启动回零，等待 `home=2`。

VOFA 设置：TCP 客户端、127.0.0.1:9090、RawData 文本、换行 `\n`。

| 命令 | 动作 |
|---|---|
| `h` | 明确选择 VOFA 手动；允许启动回零，ELRS 可离线 |
| `g -20` | HX8 目标 −20°；全局限制仍为 −90°～85° |
| `p 120` | VOFA 手动下夹爪 SERVO1 设为 120°；兼容 `p 0 120` |
| `x` / `k` | 停止 HX8并释放保持力矩；停止后需 `f` 再发角度 |
| `f` | 复位停止/故障；原因仍存在时无法恢复；回零失败则重新检查并回零 |
| `s` | 切换仅 SERVO1 独立调试，暂停 HX8；再次 `s` 回到正常遥控器启动路径 |
| `d` | 简洁/详细日志切换 |

VOFA 手动忽略遥控器摇杆和 HC13 视觉目标，采用原有 HX8 角度、速度及反馈闭环。小舵机无位置反馈。没有新的 `p` 命令时默认夹爪 90°；明确的 `p` 命令保持。`p` 在未进入任何调试入口时仍需原 `p 0 <角度>` 格式。

保留：新鲜且稳定的启动反馈、9.0～12.6 V 限制、HX8 状态保护、堵转锁存、编码器跳变检查、回零超时。若遥控器实际在线，SD 急停仍能阻止 VOFA 运动。ELRS 离线时不能依靠该遥控器急停，应使用 VOFA `x` 或切断驱动供电。`x` 释放保持力矩，承重机械臂可能因重力下落。

原 `g` 强制角度路径也补上了电压/状态保护、故障锁存和有效反馈门禁，避免绕过这些保护。单独进入小舵机调试不受 HX8 的供电/反馈故障阻塞。

`tools/test_vofa_manual.ps1` 验证离线控制授权、视觉隔离、停机/复位、在线 SD 急停及 HX8 回零保护；原 AUTO、启动角度和回零测试继续通过。组件测试不代表实物已经转动，需现场观察。
