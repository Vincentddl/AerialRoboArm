# 当前硬件接口与接线

更新：2026-11-06；请先确认固件构建。项目使用STM32F103C8T6，接口由源码`main.c`、`usart.c`、`i2c.c`、`tim.c`及BSP定义。

## UART与执行器

| 接口 | STM32引脚 | 正式控制 | V2无线调试/采集 |
| --- | --- | --- | --- |
| USART1重映射 | PB6 TX、PB7 RX | ELRS/CRSF，420000 | JY61P，115200 |
| USART2 | PA2 TX、PA3 RX | HX8/UC-01，115200 | 相同 |
| USART3 | PB10 TX、PB11 RX | HC13视觉目标，230400 | HC13 V2双向收发，230400 |
| TIM2_CH1 | PA0 | SERVO1夹爪PWM，333Hz | 显式PWM命令时启动 |
| TIM2_CH2 | PA1 | SERVO2默认关闭 | 不启动 |
| I2C1重映射 | PB8 SCL、PB9 SDA | VL53L1X，7位地址0x29 | 采集主入口不初始化此测距路径 |
| SWD | PA13 SWDIO、PA14 SWCLK | DAPLink下载和RTT | 相同 |

模块TX接MCU RX、模块RX接MCU TX，并共地。PB6/PB7接口在ELRS和JY61P之间择一，不同时接入。HC13两端串口及无线配置应匹配；电脑COM号不固定，按USB设备身份选择。

HX8链路：STM32 PA2/PA3 → UC-01逻辑接口 → HX8总线。原项目接线约定为UC-01 R接PA2、T接PA3、G共地；字母不能直接类推其他转接板，接前核对该板定义。UC-01逻辑电平按STM32接口配置为3.3V，HX8主供电独立核对。

## 供电、日志和反馈边界

- 主板、无线模块、HX8和PWM舵机分别按各自电气要求供电，信号共地。读到HX8电压不能推断其他电源轨正常。
- HC13 KEY涉及PB0预留控制，当前不将其作为普通运动输入。PC串口DTR/RTS状态曾影响通信，V2上位机在打开前关闭两者。
- DAPLink的虚拟COM口不是电脑端HC13串口。RTT通过SWD和OpenOCD TCP服务访问，不经该虚拟串口。
- SERVO1没有位置回包；HX8反馈为其内部角度和状态。相机图像通过图传/视频采集进电脑，不经HC13传输。
- 正式构建由RTT输出诊断，调试USART3已用于HC13。V2状态、命令与低频加速度也通过HC13，完整采集经RTT。

本表不表示所有接口均已在同一次实机实验中验证。硬件变更、传感器拆换和电源变化后需重新确认。旧TIM1三相PWM及AS5600链路不属于当前程序。
