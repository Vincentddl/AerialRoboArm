# HX8 明确上电归零流程

固件版本标记：`[FW] explicit_home_zero_v2 default_g=0`。

## 执行顺序

1. 启动仅查询角度；连续 300 ms 新反馈一致、无保护状态、供电 9.0～12.6 V 且角度在 -90°～85° 内后，才进入回零阶段。
2. ELRS 在线、急停释放且遥控请求 MANUAL 或 AUTO 时，执行 HX8 g0；速度 80°/s，加减速各 200 ms。遥控未准备好时等待，不绕过失联保护。
3. 连续三个新反馈确认位置在 0°±0.5° 内、相邻角变化不超过 0.25°，才完成归零。缓存反馈不会重复计数。
4. 完成后把遥控积分目标和 AUTO 保持目标初始化为 0°，丢弃回零期间积压的视觉包，然后恢复正常 MANUAL/AUTO。

归零未完成时不执行遥控摇杆目标、视觉角度跟随或视觉三帧夹取。夹爪进入 AUTO 张开和三帧稳定后闭合在回零完成后运行。完成后主臂仍持续跟随新视觉目标。

## 失效和重连

回零过程中失联、急停、供电/状态异常或反馈不新鲜会停止。5 秒未归零也停止，`[HOME] stage=3`。不自动反复冲零；条件恢复后用系统复位脉冲 SB 或 RTT `f` 重新开始，也可重启 MCU。

HX8 单独断电且 MCU 仍运行时，长断链会重新要求稳定反馈并执行同样的完整归零流程。异常/越界编码器读数不会直接夹为 -90°位置目标。普通短暂反馈波动恢复不会被当成每次开机强制归零。

`[HOME] stage=N target=0`：0=等待，1=回零中，2=已完成，3=失败。启动/回零的 `[DBG] tgt` 也显示 0°，不能混入断电前的旧目标。

0°是 HX8 原 g 坐标系的零点，回零是实际机械转动，不是修改编码器零点。软件无法排除舵机在 MCU 运行前自身的上电动作。烧录和第一次大幅回零前支撑机械臂并清空运动范围。

`tools/test_startup_angle.ps1` 同时验证稳定启动和回零状态机，覆盖到位、缓存、故障、超时与计时回绕；`tools/test_auto_pick.ps1` 验证归零后使用的跟随/夹爪流程。它们不能替代实机归零验收。
