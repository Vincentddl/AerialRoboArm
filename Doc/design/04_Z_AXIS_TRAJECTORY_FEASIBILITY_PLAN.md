# Z 轴约束目标视觉预测与抓取可行性规划书

| 项目 | 内容 |
| --- | --- |
| 项目名称 | AerialRoboArm 视觉感知与单轴抓取验证 |
| 规划对象 | 仅沿安装基座 Z 轴运动的泡沫目标 |
| 文档版本 | V1.0 |
| 编制日期 | 2026-07-14 |
| 当前结论 | 有条件可行，适合进入一维受约束预测验证阶段，暂不具备直接实抓条件 |

## 1. 项目背景

本项目拟利用安装在机械臂系统上的单目摄像头识别特定泡沫目标，估计目标相对安装基座的位置或偏移角，并预测目标在未来时刻的位置，为一轴机械臂提供抓取目标量和触发时机。

前期方案允许目标在图像平面内自由运动，采用包含位置、速度和加速度的二维 Kalman 模型进行 0.5 s 外推。实测表明，该模型容易将检测框抖动、短暂漏检和错误关联放大为不合理的速度与加速度，尚不能满足真实抓取要求。

若通过导轨、落料机构或实验约束，使目标仅沿安装基座 Z 轴运动，则问题可由二维自由轨迹预测降维为一维受约束运动估计。该约束能够显著降低状态维度、错误关联概率和模型不确定性，是当前硬件与数据条件下更可行的技术路线。

## 2. 建设目标

### 2.1 总体目标

建立以下完整链路：

```text
摄像头采集
  -> 泡沫目标检测
  -> 镜头畸变校正
  -> 检测中心投影到基座 Z 轴
  -> 一维位置与速度估计
  -> 抓取时刻/抓取位置预测
  -> 质量判定与安全门控
  -> 串口发送给 STM32
  -> 机械臂执行抓取
```

### 2.2 分阶段目标

1. 在离线录像中稳定检测并连续跟踪目标。
2. 将目标观测转换为基座 Z 轴上的一维坐标或等效机械臂位置。
3. 实现 0.15-0.25 s 的短时预测并通过独立测试集验证。
4. 在短时预测稳定后评估 0.5 s 预测，不直接预设其一定可用。
5. 根据机械臂动作延迟预测目标到达抓取平面的时刻，而非只输出固定时长后的像素点。
6. 完成低速、受控条件下的实机抓取验证。

## 3. 可行性结论

### 3.1 技术可行性

若基座 Z 轴在图像中表现为可观测的上下运动，并且目标与相机的横向位置和运动平面基本固定，则单目相机可以通过一维标定获得目标沿 Z 轴的位置变化。结合受约束运动模型，可以预测目标短时间后的 Z 轴位置或到达指定抓取位置的时间。

推荐状态模型为：

```text
x = [z, vz]

z(k+1)  = z(k) + vz(k) * dt + 0.5 * az * dt^2
vz(k+1) = vz(k) + az * dt
```

其中 `az` 不再由每一帧自由估计，而是根据运动机构确定：

- 自由抛落阶段采用重力加速度或经实验标定的等效加速度。
- 导轨、弹簧或主动机构驱动阶段采用实测的固定模型或分段模型。
- 存在明显空气阻力时，使用离线数据拟合阻尼参数，不在实时阶段无约束估计高阶状态。

### 3.2 适用边界

本方案成立需要满足以下条件：

- Z 轴指安装基座的受控运动轴，而不是默认等同于相机光轴。
- 目标横向偏离保持在允许范围内，并可由图像检测出来。
- 摄像头、镜头焦距、调焦状态、分辨率和安装位置保持不变。
- 目标运动平面或目标到相机的几何关系可标定。
- 抓取机构的动作延迟和有效抓取窗口可以测量。

若目标沿相机光轴接近或远离，目标中心在图像中的变化很小，仅靠边界框中心无法可靠获得深度。此时必须增加以下至少一种信息：

- 已知物体尺寸与稳定的目标轮廓/关键点；
- ToF 或其他距离传感器；
- 双目或深度相机；
- 机械导轨位置编码器。

## 4. 现有基础与差距

### 4.1 已有基础

当前已经具备以下工程基础：

- 2.1 mm 广角镜头与 640 x 480 图像链路。
- Fisheye 相机标定结果，有效标定图 53 张。
- 标定 RMS/重投影误差约 0.229 px。
- 泡沫目标 V6 检测模型及可回滚的历史权重。
- V6 数据集共 516 张训练图和 143 张验证图。
- V6 验证结果：Precision 0.841、Recall 0.831、mAP50 0.831、mAP50-95 0.467。
- RTX 4070 上 300 帧实测中位推理时间 9.62 ms，P95 为 18.05 ms，平均约 88 FPS。
- PC 端检测、轨迹输出和 STM32 端视觉输入接口雏形。

上述结果说明相机标定和推理速度不是当前首要瓶颈。

### 4.2 当前差距

在已有录像上，二维加速度 Kalman 模型的 0.5 s 预测中位误差约 166 px，P90 约 395 px；能够在 0.5 s 后继续找到同一轨迹的样本比例约 47.2%。该模型尚未产生有效预测增益。

主要差距包括：

1. 动态目标在工作置信度下仍存在漏检，快速运动和拖影样本不足。
2. 当前跟踪器允许二维自由运动，检测抖动会被转换为较大的速度和加速度。
3. 预测评估主要使用未来检测中心作为伪真值，缺少独立人工标注真值。
4. 尚未建立图像观测到基座 Z 坐标或机械臂位置的专用标定关系。
5. 尚未测量图传、推理、串口、MCU 响应和机械动作的端到端延迟。
6. 尚未以真实抓取成功率验证系统。

## 5. 技术方案

### 5.1 Z 轴机械约束

优先使用机械导向结构保证目标运动满足一维假设，例如透明导轨、低遮挡滑槽或固定释放机构。应测量并记录：

- Z 轴相对安装基座的物理方向；
- 目标允许的横向摆动范围；
- 释放高度和初速度范围；
- 抓取中心高度及有效抓取窗口；
- 导轨摩擦、弹性碰撞等是否导致分段运动。

横向偏差不应被模型直接忽略。程序应计算目标中心到 Z 轴投影线的垂直距离，超过阈值时将该帧标记为无效。

### 5.2 Z 轴视觉标定

相机内参只解决镜头成像和畸变问题，不能直接给出基座 Z 坐标。还需完成一维工作空间标定：

1. 在 Z 轴上设置多个已知物理位置，建议覆盖完整抓取区域并至少取 8-12 个点。
2. 每个位置采集多帧目标中心或专用标志点，先进行鱼眼去畸变。
3. 拟合去畸变像素位置与物理 Z 坐标的关系 `z = f(s)`。
4. `s` 表示目标点在 Z 轴图像投影曲线上的弧长或一维参数。
5. 使用未参与拟合的中间位置检查插值误差。

广角镜头存在明显非线性，不建议直接使用单一的“像素/毫米”比例。可优先采用单调三次插值、分段线性查表或完整几何投影模型。

### 5.3 目标观测量

第一版可继续使用目标框中心，但应同时保留以下数据：

```text
timestamp
bbox
center
confidence
blur/quality score
distance_to_z_axis
z_measurement
```

如果目标姿态变化导致边界框中心与真实质心明显不一致，应升级为关键点模型，标注一个稳定的几何中心或抓取参考点。关键点方案通常比继续增大检测模型更能改善轨迹测量质量。

### 5.4 一维跟踪与预测

推荐采用“鲁棒观测筛选 + 一维状态滤波 + 物理约束预测”：

1. 删除低置信度、严重拖影和偏离 Z 轴的观测。
2. 对最近 5-10 个有效观测使用时间戳进行一维速度估计。
3. 使用中值残差、Huber 损失或 RANSAC 抑制单帧跳点。
4. 状态量只保留 `z` 和 `vz`，加速度由运动阶段确定。
5. 分别识别上升、顶点附近和下降三个阶段。
6. 顶点附近速度接近零时降低远期预测置信度，避免方向误判。

若物理 Z 坐标暂未完成标定，可先在去畸变后的 Z 轴一维坐标上进行短时二次拟合，但该方案只能作为原型验证，不应直接作为最终物理模型。

### 5.5 抓取时机计算

固定预测 0.5 s 并不是最适合机械臂的接口。更实用的目标是求解目标何时到达抓取位置：

```text
z(t_hit) = z_grab
```

得到 `t_hit` 后，结合端到端延迟计算触发时间：

```text
t_trigger = t_hit - t_camera - t_inference - t_transport - t_mcu - t_arm
```

仅当 `t_trigger > 0` 且预测置信区间落在抓取窗口内时，才允许向 MCU 发送抓取指令。

### 5.6 输出与安全门控

建议 PC 端向 MCU 发送以下紧凑语义：

```text
valid
sequence_id
z_target_or_arm_pos
time_to_intercept_ms
confidence
prediction_sigma
timestamp_ms
```

满足下列条件后才允许 `valid=1`：

- 目标连续确认帧数达到要求；
- 检测置信度和轨迹质量达到阈值；
- 横向偏离未超过允许范围；
- 目标处于允许抓取的运动阶段；
- 预测位置和时间位于机械臂能力范围内；
- 数据时间戳未过期；
- 预测不确定度低于阈值。

MCU 端仍需执行超时、限位、重复指令抑制和故障回退，不应仅依赖 PC 的 `valid` 字段。

## 6. 数据与实验设计

### 6.1 数据采集

建议针对 Z 轴约束场景补充以下数据：

| 数据类型 | 建议数量 | 用途 |
| --- | ---: | --- |
| 静态 Z 轴标定位置 | 8-12 个位置，每点 20 帧 | 建立像素到物理 Z 的映射 |
| 开发用完整运动序列 | 至少 30 次 | 调整检测、滤波和运动模型 |
| 独立测试运动序列 | 至少 20 次 | 最终量化，禁止参与调参 |
| 目标缺失/空背景序列 | 至少 10 段 | 测量误触发率 |
| 边界工况序列 | 至少 10 段 | 覆盖拖影、偏轴、遮挡和极限速度 |

训练集、调参集和最终测试集应按“完整运动序列”划分，不能把同一段视频的相邻帧随机分到训练集和验证集，否则会高估泛化能力。

### 6.2 真值标注

最终测试集需要人工标注稳定参考点，至少记录：

- 每帧目标是否可见；
- 目标参考点像素坐标；
- 对应 Z 轴位置或标定位置；
- 目标运动阶段；
- 遮挡和拖影等级；
- 实际到达抓取平面的时刻。

若条件允许，可使用高帧率手机侧拍、光电开关或位置传感器提供独立时间真值。未来检测中心只能用于开发阶段快速评估，不能作为最终验收的唯一真值。

## 7. 量化指标与验收门槛

### 7.1 检测与跟踪

| 指标 | 原型门槛 | 实机门槛 |
| --- | ---: | ---: |
| 动态目标 Recall | >= 85% | >= 90% |
| 误触发率 | <= 2% | <= 1% |
| 连续轨迹覆盖率 | >= 80% | >= 90% |
| P95 连续漏检 | <= 5 帧 | <= 3 帧 |
| 推理延迟 P95 | <= 33 ms | <= 25 ms |

### 7.2 轨迹预测

| 指标 | 0.15-0.25 s 原型门槛 | 0.5 s 继续开发门槛 |
| --- | ---: | ---: |
| 可输出预测的轨迹覆盖率 | >= 80% | >= 85% |
| Z 轴像素误差中位数 | <= 15 px | <= 20 px |
| Z 轴像素误差 P90 | <= 30 px | <= 40 px |
| 角度误差 P90（如使用角度） | <= 3 deg | <= 5 deg |
| 到达抓取平面时间误差 P90 | <= 40 ms | <= 60 ms |

像素或角度门槛最终应换算为实际抓取位置误差。允许误差应满足：

```text
预测位置 P90 误差 + 机械臂重复定位误差
  < 抓手有效开口余量
```

### 7.3 实机验收

按固定速度、固定背景和规定释放范围完成不少于 30 次受控试验：

- 第一阶段抓取成功率达到 70%，且不得出现越限危险动作。
- 参数稳定后抓取成功率达到 80% 以上。
- 所有失败必须能够由录像、预测日志、串口日志和 MCU 状态回溯。
- 若预测质量不达标，系统必须拒绝动作，而不是输出猜测结果。

## 9. Go/No-Go 决策点

### Gate 1：观测是否成立

若不同 Z 位置在图像中不能形成稳定、单调且可重复的一维映射，停止纯单目方案，增加 ToF、编码器或调整相机视角。

### Gate 2：检测是否足够连续

若补光、曝光优化和数据补训后动态 Recall 仍低于 85%，不进入 0.5 s 预测，应优先解决成像和关键点观测问题。

### Gate 3：短时预测是否产生增益

只有当 0.15-0.25 s 受约束模型明显优于“保持当前位置”和“简单匀速”基线，并达到 P90 误差门槛，才继续测试 0.5 s。

### Gate 4：是否允许实机动作

只有当独立测试集达标、端到端延迟已测量、安全门控有效并完成空载测试后，才允许连接机械执行机构。

### Gate 5：是否具备工程可用性

若受控实机成功率低于 70%，应回退到数据、观测模型或机械结构阶段，不应通过降低安全阈值掩盖问题。

## 10. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 高速运动拖影 | 漏检、中心漂移 | 增加照明、缩短曝光、提高有效帧率 |
| 广角非线性 | Z 轴映射误差 | 先去畸变，再使用分段或几何标定 |
| 边界框中心不稳定 | 速度估计发散 | 训练稳定关键点，使用鲁棒残差筛选 |
| 目标偏离 Z 轴 | 一维模型失效 | 机械导向并设置横向偏差门控 |
| 目标沿相机光轴运动 | 单目深度不可观 | 增加 ToF、尺寸约束或调整相机视角 |
| 0.5 s 预测过长 | 误差快速累积、目标出画 | 先验证短时预测，改为拦截时刻求解 |
| 通信或动作延迟变化 | 错过抓取窗口 | 全链路时间戳、延迟标定和超时拒绝 |
| 训练/测试数据泄漏 | 指标虚高 | 按完整视频序列划分数据集 |
| 错误预测触发机械臂 | 设备或人员风险 | PC 与 MCU 双重门控、限位、急停和低速分级测试 |

## 12. 最终建议

该方案具备继续研发价值，但可行性的核心来自“机械约束 + 一维物理模型 + 独立真值验证”，而不是继续增加二维 Kalman 模型复杂度。

建议立即执行以下顺序：

1. 明确基座 Z 轴与相机光轴的关系，并固定一维运动机构。
2. 完成 Z 轴多点标定和独立位置误差测试。
3. 修改当前轨迹程序，使用 `[z, vz]` 状态和固定/标定加速度。
4. 先量化 0.15-0.25 s 预测，再决定是否保留 0.5 s 指标。
5. 达到离线门槛后再接入 MCU 和机械臂，逐级开展低速实机验证。

综合判断：**仅沿基座 Z 轴运动的目标预测在技术上可行，当前系统具备开展原型验证的基础；但检测连续性、Z 轴几何标定、预测模型和端到端时序仍需完成，现阶段不得将预测结果直接用于无人值守抓取。**
