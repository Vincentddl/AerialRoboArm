# 视觉感知模块设计说明

## 1. 模块定位

视觉感知模块用于为 AerialRoboArm 提供面向任务目标的视觉语义输入。该模块不直接承担机械臂执行器闭环控制职责，而是负责完成相机几何校正、目标识别定位、目标相对安装基座的角度或位置估计，并将紧凑、可解释的感知结果提供给上层决策与 STM32 控制链路。

当前阶段的视觉部分主要包括相机镜头更换后的几何校正与特定目标识别定位。更换 2.8mm 镜头后，需要重新进行相机内参标定和畸变校正，获得实际焦距、主点和畸变参数，并结合摄像头相对机械臂安装基座的安装角与位置偏移，建立从图像坐标到安装基座坐标系的转换关系。在此基础上，针对任务目标采集数据并训练目标检测或识别模型，输出目标中心、边界框或关键点信息，进一步估计目标相对安装基座的偏移角或空间位置，并可结合连续帧进行目标运动趋势预测。

在系统级流程中，视觉感知模块位于 PC 端或伴随计算设备上，典型数据链路如下：

```text
模拟图传/摄像头采集画面
  -> PC 接收图像
  -> PC 运行目标检测模型
  -> 计算目标中心、偏移角、轨迹预测或未来位置
  -> 结合 ToF 测距
  -> 通过串口发送抓取语义给 MCU
  -> MCU 控制一轴机械臂执行抓取
```

## 2. 核心任务

### 2.1 镜头更换后的几何校正

更换 2.8mm 镜头后，原有相机内参和畸变参数不再可靠，必须重新标定。该任务的目标是获得新镜头在实际安装与调焦状态下的相机模型参数，包括：

- 焦距参数 `fx`、`fy`
- 主点坐标 `cx`、`cy`
- 径向畸变参数
- 切向畸变参数
- 去畸变映射或校正后的图像输出

标定结果应保存为 `camera_calib.yaml` 或 `camera_calib.json`，作为后续目标定位和偏移角计算的基础输入。

### 2.2 特定目标识别与相对基座定位

针对任务目标采集图片或视频数据，建立特定目标检测/识别模型。模型输出可以根据任务精度分为三个层级：

- 目标框：输出目标边界框和中心点，适合快速估计目标相对基座的偏移角。
- 关键点：输出目标上若干稳定结构点，适合提高姿态估计和定位稳定性。
- 位姿：结合已知物体尺寸和 PnP 方法估计目标相对相机或基座的空间位姿。

在当前样机阶段，如果仅需要计算“目标偏离安装基座的角度”，目标框中心点即可作为第一版输入；如果后续需要计算目标姿态或精确空间位置，则应优先训练关键点模型，或使用已知物体尺寸进行 PnP 位姿估计。

### 2.3 一轴机械臂控制量映射

当前机械臂是一轴机械臂，Y 方向固定，X 与 Z 由机械臂固有运动曲线一一对应。因此视觉模块最终不一定需要输出完整三维坐标，而应优先将视觉结果映射为机械臂可直接消费的单一控制量，例如：

```text
arm_pos / servo_angle / step_count / trigger_time
```

该映射可以通过实测查表或轨迹函数完成：

```text
arm_pos -> X,Z
X -> Z=f(X)
X -> arm_pos
```

对于 MCU 侧，更实用的控制信息可以是 `arm_pos`、预测提前量和触发条件，而不是完整的 `X, Y, Z` 坐标。

## 3. 技术路线

### 3.1 镜头校正流程

```text
2.8mm 镜头安装
  -> 调焦
  -> 棋盘格或 ChArUco 标定图采集
  -> 相机内参标定
  -> 获得 fx, fy, cx, cy 和畸变参数
  -> 图像去畸变
  -> 保存 camera_calib.yaml/json
```

建议优先使用 ChArUco 标定板，因为其角点识别稳定性较好，对部分遮挡和拍摄角度变化更友好。标定图片应覆盖画面中心、边缘和四角区域，并包含不同距离、不同倾角和不同旋转角度。

### 3.2 安装补偿流程

```text
测量摄像头下倾角、左右偏角、滚转角
  -> 测量相机光心到机械臂安装基座的三轴偏移
  -> 建立 R_base_cam 和 t_base_cam
  -> 将相机坐标系射线或点转换到安装基座坐标系
```

其中 `R_base_cam` 表示相机坐标系到安装基座坐标系的旋转关系，`t_base_cam` 表示相机光心相对安装基座原点的位置偏移。若当前阶段难以直接获得精确外参，可先记录安装角度和安装偏移的实测值，并在实机测试中通过目标点校准进行修正。

### 3.3 目标识别流程

```text
采集特定物体图片/视频
  -> 数据清洗与场景覆盖
  -> 标注目标框或关键点
  -> 训练 YOLO 或轻量检测模型
  -> 导出推理模型
  -> 输出目标类别、置信度、中心点、边界框或关键点
```

模型选择应优先服从部署环境和实时性要求。若目标检测在上位机或伴随计算设备运行，可使用 YOLO 系列轻量模型；若后续需要边缘端部署，则应进一步评估模型大小、推理帧率、量化精度和硬件加速条件。

对于当前白色泡沫块或泡沫球目标，公开数据集很难完全覆盖实际图传画质、真实背景、真实光照和目标形态。公开数据可以作为辅助预训练或补充数据，但最终应采集本项目真实场景数据并微调模型。起步建议为：

- 正样本：500-1000 张
- 验证集：100-200 张
- 负样本：200-500 张
- 干扰物：白纸、白塑料袋、反光白物体、背景噪声和抓取失败后的混乱场景

若只需要目标中心点，优先使用 YOLO11s 或 YOLO11m 检测模型；若需要轮廓，可使用分割模型；若需要旋转角度或姿态，应考虑 OBB、关键点或 PnP 位姿估计。

### 3.4 目标估计流程

```text
目标像素点
  -> 去畸变
  -> 根据相机内参生成相机坐标系射线
  -> 使用 R_base_cam 和 t_base_cam 转换到安装基座坐标系
  -> 估计目标相对安装基座的偏移角或空间位置
```

对于只需要偏移角的场景，可以将目标中心点相对主点的偏差转换为水平和竖直视角偏差。对于需要空间位置的场景，需要引入额外约束，例如目标所在平面、目标实际尺寸、深度信息，或由关键点 PnP 估计得到的目标位姿。

### 3.5 连续帧预测流程

```text
连续帧目标位置
  -> 异常检测与低置信度剔除
  -> 滤波、Kalman 或滑动平均
  -> 估计速度与运动趋势
  -> 预测下一时刻目标位置或偏移角
```

预测结果应作为辅助量使用，不应在低置信度、目标丢失或运动突变时直接覆盖实时观测结果。当前阶段可以先使用滑动平均或一阶滤波降低抖动，后续再引入 Kalman 滤波进行目标运动趋势估计。

如果目标是平稳移动物体，例如传送带或缓慢运动目标，可以先使用匀速 Kalman 模型，状态量为：

```text
[u, v, vu, vv]
```

其中 `u, v` 为目标中心像素坐标，`vu, vv` 为像素速度。若目标是向上抛出的泡沫球，0.4s-0.5s 的预测时间已经偏长，匀速模型误差可能较大。此时应优先评估以下方案：

- 匀加速 Kalman，状态量为 `[u, v, vu, vv, au, av]`
- 最近 N 帧二次曲线拟合
- 多模型预测或规则切换

二次曲线拟合可作为工程验证优先方案：

```text
u(t) = a1*t^2 + b1*t + c1
v(t) = a2*t^2 + b2*t + c2
```

对于 30 FPS 图像，建议至少观察 8-12 帧后再进行 0.4s-0.5s 级别预测，并通过实测误差决定是否需要更复杂的多模型预测。

### 3.6 ToF 与视觉触发融合

ToF 模块可用于提供目标距离或抓取触发窗口。推荐逻辑是由摄像头计算目标偏移角度，由 ToF 持续测距，当目标角度、距离和检测置信度同时满足条件时，MCU 再执行抓取。

```text
confidence > threshold
abs(angle_x) < angle_threshold
distance_min < tof_distance < distance_max
连续满足 N 帧
触发抓取
```

示例阈值可以从以下范围起步：

```text
abs(angle_x) < 2 deg
tof_distance in [120 mm, 150 mm]
连续 3-5 帧满足
```

需要注意的是，ToF 测到的不一定就是图像中的目标。只有当目标接近摄像头光轴、ToF 测距方向和机械爪抓取方向的共同中心区域时，ToF 数据才最可信。因此相机光轴、ToF 方向和机械爪抓取方向应尽量机械对齐，并在软件侧设置中心区域触发策略。

## 4. 坐标关系与输出定义

### 4.1 坐标系

- 图像坐标系：以像素为单位，原点位于图像左上角。
- 相机坐标系：以相机光心为原点，Z 轴沿相机光轴方向。
- 安装基座坐标系：以机械臂安装基座或视觉安装基准点为原点，用于表达目标相对机械臂本体的偏移。

### 4.2 推荐输出

视觉模块对控制系统输出紧凑语义结果，而非原始图像流。推荐输出字段包括：

```text
target_valid        目标是否有效
target_class        目标类别
confidence          检测置信度
pixel_center_u/v    目标中心像素坐标
bbox_x/y/w/h        目标边界框
angle_yaw           相对安装基座的水平偏移角
angle_pitch         相对安装基座的俯仰偏移角
position_x/y/z      可选，相对安装基座的位置估计
timestamp_ms        感知结果时间戳
```

对于 STM32 侧，建议只接收必要的低带宽结果，例如 `target_valid`、`angle_yaw`、`angle_pitch`、`confidence` 和 `timestamp_ms`。目标框、关键点和调试图像应保留在上位机或感知端用于诊断。

在一轴机械臂抓取场景中，PC 到 MCU 的串口消息可进一步压缩为面向动作的语义字段：

```json
{
  "valid": 1,
  "cls": "white_foam_ball",
  "conf": 0.92,
  "angle_x": -1.5,
  "tof_mm": 135,
  "arm_pos": 1260,
  "predict_ms": 400
}
```

其中 `arm_pos` 是视觉、ToF 和机械臂标定曲线综合后的最终控制目标。若 MCU 侧资源紧张，可进一步使用定长二进制帧或紧凑 ASCII 协议，只保留 `valid`、`arm_pos`、`tof_mm`、`confidence` 和 `timestamp/predict_ms`。

## 5. 需要保存和迁移的资料

视觉感知模块的可复现性依赖完整的数据与参数归档。建议至少保存以下资料：

- 标定图片
- 相机内参文件 `camera_calib.yaml` 或 `camera_calib.json`
- 镜头型号、调焦状态和图像分辨率记录
- 安装外参记录，包括 `R_base_cam`、`t_base_cam` 或安装角度与位移
- 特定目标训练数据集
- 标注文件
- 训练脚本
- 模型权重
- 测试视频或测试图片
- 偏移角计算脚本
- 典型测试结果和误差记录

## 6. 阶段实施建议

第一阶段以“可用偏移角”为目标。完成 2.8mm 镜头标定、图像去畸变、目标框检测和目标中心点偏移角计算，先建立从目标像素中心到基座偏移角的稳定链路。原型阶段可以先使用 COCO 预训练模型验证摄像头读取、检测输出和 JSON/JSONL 结果链路，但白色泡沫块或泡沫球最终需要自建数据集微调。

第二阶段提高定位稳定性。补充安装外参标定，记录相机相对安装基座的下倾角、左右偏角和光心偏移，并加入连续帧滤波，降低目标框抖动对控制输入的影响。

第三阶段接入 ToF 与串口闭环。完成 PC 端视觉结果到 MCU 的串口发送模块，并建立 `angle_x + tof_mm -> arm_pos` 的映射关系，验证“摄像头/图传 -> PC 检测 -> 预测 -> 串口 -> MCU -> 抓取动作”的完整链路。

第四阶段扩展到空间位置、目标姿态或上抛目标预测。根据目标结构训练关键点模型，或利用已知物体尺寸进行 PnP 位姿估计，输出目标相对安装基座的空间位置和姿态信息；若采用上抛泡沫球方案，应将匀速预测升级为二次拟合或匀加速 Kalman，并以实际抓取成功率作为最终评价指标。

## 7. 风险与注意事项

- 镜头更换、分辨率变化、重新调焦或相机固定方式变化后，都需要重新检查内参和畸变参数。
- 安装外参误差会直接转化为目标偏移角或空间位置误差，应尽量固定相机安装结构。
- 目标框中心点适合估计方向偏差，但不一定等价于真实几何中心。
- 单目视觉若没有目标尺寸、平面约束或深度信息，无法独立获得可靠绝对距离。
- 模型训练数据应覆盖真实光照、背景、距离、运动模糊和目标姿态变化。
- 控制链路应设置置信度阈值和目标丢失策略，避免低质量视觉结果直接触发危险动作。
