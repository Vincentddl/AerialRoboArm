## 2. 核定质量与关键几何参数

- **CAD 仿真基线总质量**：`445.5848 g`（任务侧 `119.8 g` + 补偿侧电控配重组件 `156.4 g`［占 `35.1%`，未加装专用配重块］+ 固定基座组件 `169.4 g`；实物样机含全车线束、接插件与电池绑带实测总重 `506 g`）。
- **关键机构尺寸**：前后平行摆臂孔心距 `210 mm`，下端水平联动杆总孔心距 `265 mm`（底边铰接距 `100 mm` + 前伸悬臂段 `165 mm`），双侧长齿末端夹爪长 `178 mm`（单姿态水平几何覆盖带约 `95 mm`）。
- **传动规格**：主驱动舵机端 `M = 0.8, Z = 40`（黄铜）驱动前后摆臂与反向补偿臂 `M = 0.8, Z = 48`（铝合金 ×4），传动比 `i = 48 / 40 = 1.2`，实现任务臂前伸与电控补偿臂等角反向同步摆动。
